# Textbook

Use for mathematics or technical teaching material. Introduce a problem,
motivation, or familiar object before its formal definition, theorem, notation,
or example. Weave exposition through formal blocks:

`narrative → formal statement → explanation/example → consequence`.

State domains, assumptions, and symbol meanings before formulas. A proof is a
continuous argument: establish the starting facts, explain each non-obvious
transition, and state the resulting claim. Do not replace proof logic with an
unexplained list of “steps”.

Use examples to make an abstract definition operational; use exercises only
after prerequisites and a worked example establish the required technique.
Keep a consistent theorem, definition, example, remark, and exercise hierarchy.
Do not add generic process commentary or ornamental emphasis.
