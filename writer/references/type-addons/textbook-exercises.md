# Textbook exercise add-on

Load with `../types/textbook.md` when exercises or reference solutions are part
of the deliverable. This file defines the pedagogical and content contract; the
active format and any format integration define source-file layout when one is
needed.

## Content contract

- Introduce the prerequisites and at least one worked example before assigning
  an exercise that depends on them.
- Order exercises from direct application to synthesis or transfer. State the
  requested object, assumptions, and expected form of the answer.
- A reference solution should expose the decisive reasoning and intermediate
  results. Do not replace a derivation with a result-only answer or a vague
  statement that constraints “give” the result.
- Keep question, hint, solution, and final answer semantically distinct. Do not
  repeat the full question in an answer appendix unless the chosen format or
  template requires it.
- Keep a consistent hierarchy for exercises, subquestions, hints, solutions,
  and optional extension problems.

The add-on does not require exercises for every textbook and does not define
LaTeX commands, appendix filenames, list environments, or formula layout.
